# Snake huEVO — Node.js API (Render)

Серверный прототип для Snake huEVO. Отдельный репозиторий **snake-api**; не загружайте секреты в GitHub.

## Развёртывание

1. Создайте **публичный** (или приватный, если поддерживается подключением Render) репозиторий `snake-api` на GitHub.
2. Загрузите файлы **из корня архива** в корень репозитория (не вложенной папкой).
3. В Render создайте **Web Service** из репозитория; можно выбрать **Blueprint** по `render.yaml` (доступность Free зависит от аккаунта/региона).
4. Runtime Node, build `npm install`, start `npm start`. Переменные окружения в Render: `HUEVO_APP_ID`, `HUEVO_CLIENT_ID`, `HUEVO_CLIENT_SECRET`, `SNAKE_SESSION_SECRET` (случайная строка 32+ знаков, если Render не создал сам), `NODE_ENV=production`.
5. После деплоя `https://<service>.onrender.com/health` должен вернуть `{ "ok": true, "service": "snake-api" }`.
6. **Не меняйте** адрес уже одобренной игры, пока не проверили SDK в iframe и авторизацию с настоящей подписью `hu_hash`. Если переключите адрес игры на Render, проверьте точный origin без редиректа.

## Важно

- Это **прототип**: счёт и баланс яблок принимаются от клиента и **не защищены от накрутки**. Не используйте рейтинг для наград или реальных платежей.
- JSON-база `data.json` хранится на локальном диске и на бесплатном Render **не является постоянной**: данные могут исчезнуть после перезапуска/нового деплоя. Для настоящего облачного сохранения нужна постоянная база данных.
- Во фрейме huEVO запросы подписываются платформой; сервер проверяет `hu_hash` и затем выдаёт свой Bearer-токен. Секрет нужен **только серверу**.
- `GET /me/friends` доступен с согласия игрока через `huevo.requestAccess(['friends'])`; токен передаётся серверу один раз. API не подтверждает привязку токена к владельцу сессии — дополнительная проверка нужна перед использованием для чувствительных действий.
- HTTPS предоставляется Render. Приложение и API этого прототипа обслуживаются одним Node.js-сервером из `public/index.html`, так избегаются CORS-проблемы. Отдельный GitHub Pages по-прежнему остаётся неизменным.
